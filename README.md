# 🌸 Word Counter

A simple and cozy little tool that counts letters, numbers, symbols, words, and sentences in real time.

---

### ✨ Features

- Live counting while you type
- Separates **letters**, **numbers**, and **symbols**
- Counts words and sentences
- Soft random gradient backgrounds (click the 🌸 button)
- Pixel-inspired cute design

---

### 🛠️ Built with

- HTML
- CSS
- Vanilla JavaScript

---

### 🚀 How to use

1. Open `index.html` in your browser
2. Type or paste any text
3. Watch the counters update
4. Click the 🌸 button to change the background
